# 提案 v2 — 隱私守護的長者居家 Edge AI 防護網

> 對應題目：恩智浦 X 安富利 題目二「面向萬物互聯的下一哩路：AI 與邊緣運算在跨域整合的無限可能」
> 主硬體：FRDM-IMX93（Edge AI + HMI + Connectivity 中樞）

---

## 一、現在痛點

台灣長照的補助機器稍微沒意義，每天定時要獨居長者去定點按下報平安的按鈕（如 [圖片1.jpg](圖片1.jpg)）；如果真的在家中角落跌倒、而沒有按下按鈕，可能已經過了數個小時才會發現並通知家屬。

有些子女為了能更即時的關心家中長輩的安危，會自費購買監視器（如 [圖片2.png](圖片2.png)），通常這類產品可以用手機 APP 看到遠端家中的狀況。但有兩個沒被解的問題：

1. **沒人能 24 小時盯著手機** — 真的跌倒時，子女不會剛好打開 APP 看到。
2. **隱私焦慮** — 長輩在家穿著輕便、上廁所、洗澡、和朋友聊私事，沒人想要這些畫面隨時被串流到雲端、或被任何人遠端看到。這是現有監視器類產品**做不出來、也不敢做**的真正痛點。

---

## 二、我們的解決辦法

### 2.1 系統架構（pipeline）

主機：**FRDM-IMX93** 連接 USB camera + 麥克風，作為邊緣推論中樞（server）。
邊緣節點：其他房間以 **ESP32-CAM + 麥克風** 佈署，將影像與音訊串到 IMX93 做集中運算。

> 在 IMX93 上同時跑：人體骨架偵測（跌倒判斷）+ 喚醒詞偵測（「救命」、「啊」等求救聲、「取消」、「沒事」等取消詞）。

### 2.2 對齊題目四大評分面向

| 評分面向 | 我們的對應做法 |
|---|---|
| **AI Perception 智能感知** | 影像（pose / fall）+ 音訊（KWS / 求救聲）多模態邊緣推論 |
| **AI-driven Control 智能決策** | 偵測 → 邊緣對話確認 → 分級告警的閉環決策（見 §3） |
| **HMI 智能互動** | IMX93 端對長輩本人的本地語音安撫與互動（見 §4） |
| **Connectivity & Interoperability** | 多房間 sensor node ↔ IMX93 ↔ LINE 家屬通知；未來可串智慧家庭（§6） |
| **Security（加分）** | 影像沒事不出門：本地推論、零雲端串流（見 §5） |

---

## 三、把「通知」升級成「邊緣閉環決策」（AI-driven Control）

現有產品的通病是「偵測到 → 直接通知」，誤報率高，家屬收多了假警報就會逐漸麻木忽略。我們在邊緣做一層**主動對話確認**：

```
[偵測到跌倒 / 救命] 
        ↓
IMX93 主動語音：「偵測到您可能跌倒，您還好嗎？10 秒內回應否則通知家人。」
        ↓
        ├── 聽到「取消 / 沒事」(取消詞)               → 取消告警，紀錄事件
        └── 聽到「救命 / 啊」或是「10 秒內無回應」    → 立即通知家屬 + 允許家屬手機的APP 2小時內看即時影像
```

這一層做了三件事：

1. **降低誤報** — 沙發上躺平、彎腰撿東西不會被誤通知。
2. **讓長者有掌控感** — 不是被監視，而是被陪伴。
3. **體現邊緣 AI 的決策能力** — 不是把判斷丟雲端，IMX93 在現場就把整段流程跑完。

---

## 四、HMI 智能互動 — 對長輩本人發聲

我們在 IMX93 端做本地語音 + 視覺回饋：

- **跌倒當下**：「偵測到您可能跌倒，已經為您發送通知給您的家屬，請保持冷靜。」
- **求救觸發後**：「已通知家人，請保持冷靜，救援正在路上。」
- **取消告警時**：「好的，已為您取消通知，注意安全。」

---

## 五、Security / Privacy — 把痛點變成加分項

監視器產品最大的隱私焦慮在於「**畫面是否會離開我的家**」。現有產品的答案幾乎都是「會（傳雲端 / 雲端錄影）」。我們的答案是 — **不會，除非真的出事**。

**「隱私保護的 Edge AI 防護網」設計：**

| 狀況 | 影像處理位置 | 是否離開家中 |
|---|---|---|
| 平時（無事件） | 僅在 IMX93 / ESP32-CAM 本地做骨架偵測與 KWS | **完全不出家門**，無串流、無上雲、無錄影 |
| 偵測到跌倒/求救（觸發後） | 本地判斷後截圖透過 LINE 傳家屬，**並開放家屬手機 APP 在 2 小時內看即時影像** | 僅在事件觸發後的限時窗口內，最小資料外傳 |
| 2 小時時限到 | 立即關閉遠端串流通道，回到平時狀態 | 即時中斷，無持續錄影 |

**對應 IMX93 的 Security 能力可宣告：**

- 利用 i.MX93 的 secure boot / EdgeLock 子系統做韌體完整性保護，避免攝影機被植入後門。
- 邊緣節點（ESP32-CAM）↔ IMX93 之間以 TLS / mTLS 通訊，避免家中 WiFi 被竊聽即洩漏影像。
- 所有事件 log 僅存本地，家屬端 LINE 通知為**文字 + 單張截圖**，不是持續串流。

> 一句話：**「平時你看不到，出事才看得到」**，這是現有監視器做不到、也是評審 Security 加分項要的答案。

## 六、Rebuttal（評審可能會問）

**Q1：現在也有穿戴式裝置可以偵測跌倒，準確度更高，為何還需要鏡頭？**
A：根據我們對家中長輩的觀察，長輩常因身體不適或忘記而沒戴手環/手錶，覆蓋率不穩。我們的系統只要插頭通電就持續運作，零依賴使用者配合。

**Q2：跌倒偵測模型誤報怎麼辦？**
A：我們不只靠單一影像模型。架構上有「**影像 pose + 音訊事件 + 邊緣對話確認**」三層融合 — 視覺判斷 → 音訊輔助（撞擊聲/呻吟）→ 主動語音問安。能取消的就在邊緣取消，不會狼來了。

**Q3：和市售雲端監視器（Tapo、小米、Google Nest）差別？**
A：(1) 隱私 — 我們影像不出家門；(2) 主動性 — 我們會發聲關心長者本人；(3) 離網仍可運作 — 雲端服務掛了我們仍會在家中本地告警；(4) 可擴展為療養院級多節點架構（見 §7）。

## 七、Future Work — 跨域延伸

### 7.1 同一架構打四個場景（直接對應題目「跨域整合」精神）

| 場景 | 部署方式 | 主要使用者 |
|---|---|---|
| **家用**（主場景） | 1× IMX93 + N× sensor node 鋪滿全家 | 獨居長者、家屬 |
| **療養院** | 1× IMX93 / 樓層，多房間集中監控 | 護理站、看護 |
| **獨居老人社區** | 多戶 IMX93 + 區公所 dashboard | 里長、社工 |
| **醫院病房** | 拔管 / 離床 / 跌床偵測 | 護理師、院方 |

我們的 sensor node ↔ IMX93 階層式架構天然支援水平擴展，由「家用」放大到「機構級」幾乎不用重寫。

### 7.2 與智慧家庭裝置整合（強化 AI-driven Control 閉環）

當確認長者真的需要協助時，IMX93 不只通知家屬，還能同步：

- **開啟全屋大燈** — 救護員到場時環境清楚。
- **解鎖大門 / 啟動智慧門鎖緊急模式** — 救護員可進入，家屬不需在場。
- **關閉瓦斯爐 / 關水** — 防止跌倒當下未關火造成二次災害。
- **觸發智慧音箱大聲廣播求救** — 通知鄰居。

透過 Matter / MQTT / Home Assistant 整合，IMX93 從「偵測器」進化成名副其實的 **Smart Space Controller**（題目情境的原文用詞）。

### 7.3 進階多模態融合

- 加入跌倒後的「無動作時間」判斷（停止移動超過 N 秒才告警）。
- 結合環境感測（溫度異常、瓦斯洩漏）做複合告警。
- 利用 MCXN947 等 low-power MCU 作 always-on 前哨節點（聲音事件喚醒 IMX93 才開鏡頭推論），進一步降功耗、強化「MCU + MPU 階層式 Edge AI」的故事。
