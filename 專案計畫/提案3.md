# 提案 v3 — 隱私守護的長者居家 Edge AI 防護網

> 題目：恩智浦 X 安富利 題目二「AI 與邊緣運算在跨域整合的無限可能」
> 主硬體：FRDM-IMX93

---

## 一、痛點

- **報平安按鈕**：定時按一下沒意義，跌倒沒按可能數小時無人發現。
- **市售監視器**：沒人 24 小時盯著手機；長輩日常被串雲端，**隱私焦慮無解**。

## 二、解法

**FRDM-IMX93** 接 USB camera + 麥克風作邊緣推論中樞，其他房間以 **ESP32-CAM + 麥克風** 串影音回 IMX93。本地同時跑：人體骨架偵測（跌倒）+ 喚醒詞偵測（救命 / 取消詞）。

### 對齊四大評分面向

| 面向 | 對應做法 |
|---|---|
| **AI Perception** | 影像 pose + 音訊 KWS 多模態邊緣推論 |
| **AI-driven Control** | 偵測 → 邊緣對話確認 → 分級告警閉環（§3） |
| **HMI** | IMX93 端對長者本人的本地語音安撫（§4） |
| **Connectivity** | sensor node ↔ IMX93 ↔ LINE 家屬通知 |
| **Security（加分）** | 影像沒事不出門：本地推論、零雲端串流（§5） |

---

## 三、邊緣閉環決策（AI-driven Control）

不要偵測到就通知，加一層**主動對話確認**降低誤報：

```
[偵測到跌倒 / 救命]
        ↓
IMX93 主動語音：「偵測到您可能跌倒，您還好嗎？10 秒內回應否則通知家人。」
        ↓
        ├── 「沒事 / 我沒事」(取消詞) → 取消告警，紀錄事件
        └── 「救命 / 啊」或 10 秒無回應 → 通知家屬 + 允許家屬 APP 2 小時內看即時影像
```

效果：降低誤報、長者有掌控感、決策完全在邊緣完成。

---

## 四、HMI — 對長者本人發聲

- **跌倒當下**：「偵測到您可能跌倒，已通知家屬，請保持冷靜。」
- **求救觸發**：「已通知家人，救援正在路上。」
- **取消告警**：「好的，已為您取消通知。」

對「當下最需要被安撫的人」發聲，是現有產品完全沒做的事。

---

## 五、Security / Privacy — 把痛點變成加分項

**「平時你看不到，出事才看得到」**

| 狀況 | 影像處理位置 | 是否離開家中 |
|---|---|---|
| 平時無事件 | IMX93 / ESP32-CAM 本地推論 | **不出家門**，無串流、無上雲 |
| 偵測到跌倒/求救 | 本地判斷後才截圖傳 LINE | 事件當下，最小外傳 |
| 家屬主動查看 | 端對端加密，2 小時時限 | 點對點，不經雲端錄影 |

搭配 IMX93 的 **EdgeLock / secure boot** 與邊緣節點 mTLS，把隱私焦慮直接變成 Security 加分。

---

## 六、Rebuttal

- **為何不用穿戴式？** 長輩常忘戴/不適而沒戴；插頭通電即運作，不依賴使用者。
- **誤報怎麼辦？** 影像 pose + 音訊事件 + 主動對話確認三層融合。
- **和 Tapo / 小米差在哪？** 隱私（影像不出門）、主動性（對長者發聲）、離網可用、可擴展機構級。
